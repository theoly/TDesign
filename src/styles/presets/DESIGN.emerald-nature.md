# DESIGN SPECIFICATION · 极客赛博 (emerald-nature)

## 1. 设计哲学与基调 (Vision & Tone)
- **基调**: Cyber / High-Tech 极客赛博风格，电光青蓝、冷色辉光、紧凑锐利。
- **视觉气质**: 高对比度深色为主轴，搭配强烈的毛玻璃背景模糊与电光青蓝轮廓光。
- **结构原则**: 面向控制台、运维监控或数据密集型场景，极高屏幕利用率。

## 2. 60-30-10 配色法则 (Color Strategy)
- **60% 基础底色**:
  - 极暗背景配合半透明表面 (`--color-surface` + `--blur-md`)，营造悬浮 HUD 质感。
- **30% 结构层级**:
  - 荧光白与高对比冷灰文本，清晰的数据网格描边 (`--color-border`)。
- **10% 品牌强化与行动点**:
  - 主行动点与重点监控指标使用电光青蓝 (`--color-primary`)，结合 `--shadow-glow` 发光投影。

## 3. 排版节奏与信息密度 (Typography & Density)
- **字体与比例**: 推荐数字与代码块使用等宽字族 `--font-mono`，信息展示紧凑。
- **密度刻度**: `compact` 高密度紧凑刻度，容器内边距 `p-3` (12px) 或 `p-4` (16px)，小步长间距。
- **圆角**: 微倒角 `--radius-sm` (4px) 或 `--radius-md` (8px)，凸显科技感硬朗轮廓。

## 4. 严禁事项与负面约束 (Negative Constraints)
- **严禁大面积暖色**: 禁止使用暖黄、暖粉等冲突色系。
- **严禁松散留白**: 避免过大的无效留白，确保关键监控指标一览无余。
- **严禁非规范发光**: 发光效果只能用于按钮聚焦或核心报警指示，禁止整屏乱发光。
