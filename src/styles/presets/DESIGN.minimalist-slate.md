# DESIGN SPECIFICATION · 极简性冷淡 (minimalist-slate)

## 1. 设计哲学与基调 (Vision & Tone)
- **基调**: Apple / Vercel 极简性冷淡风格，黑白灰单色对比、大面积留白。
- **视觉气质**: 几乎不使用彩色高亮，依托极致的字体字重（400 vs 600）与微弱中性色差区分层级。
- **结构原则**: 超平坦设计，近乎零投影，线条克制，极高辨识度与极简现代感。

## 2. 60-30-10 配色法则 (Color Strategy)
- **60% 基础底色**:
  - 浅色模式使用纯净亮白与极致浅灰底色；
  - 深色模式使用深邃纯黑 (#09090b) 底色。
- **30% 结构层级**:
  - 核心文本 `--color-text-primary`，辅助说明使用中性冷灰 `--color-text-secondary`；
  - 分隔线使用 `--color-border-subtle`，仅保留必要的微边界。
- **10% 品牌强化与行动点**:
  - 主操作按钮使用高对比黑底白字或白底黑字反显 (`--color-primary`)；
  - 严禁添加彩色强调色或饱和光晕，保持单色调绝对纯粹。

## 3. 排版节奏与信息密度 (Typography & Density)
- **字体与比例**: 强调大字重对比与干净的无衬线排版，行高宽松（1.5~1.625）。
- **密度刻度**: `spacious` 宽松留白哲学，内边距推荐使用 `p-6` (24px) 或 `p-8` (32px)，保持界面呼吸感。
- **圆角**: 小圆角或微圆角 `--radius-sm` (4px) 或 `--radius-md` (8px)，突出工业切割感。

## 4. 严禁事项与负面约束 (Negative Constraints)
- **严禁过度阴影**: 禁止在普通卡片上添加重度弥散投影，保持平坦（Flat/Neobrutalist）风格。
- **严禁炫目光晕**: 禁用强发光效果或彩色渐变背景。
- **严禁未定义类名**: 严格依赖白名单类名与 CSS 变量。
